# Code of conduct

Be kind, be patient, and assume good intent. Critique work, never people. Harassment, insults and discrimination of
any kind aren't welcome here, in issues, pull requests, or anywhere else the project lives.

Maintainers may edit or remove comments, and block people, who don't follow this. To report something privately,
use GitHub's private vulnerability reporting or contact the maintainer through their GitHub profile.

This project follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
