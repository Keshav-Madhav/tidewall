Tidewall

A live wallpaper for macOS that flows around your windows. Move a window and the world grows, parts and settles around it.
Version 1.0macOS 14+GPL-3.0
Software updateChecks GitHub for new versions.
Update automaticallyDownload new versions and install them while your screen is locked.
Tidewall began as a fork of Deskland. Data, models, paintings and libraries keep their own licences: Natural Earth, Open-Meteo, d3-celestial, three.js, the Smithsonian, NASA, Poly Haven, Khronos and The Met. Some textures and models were generated for Tidewall.
